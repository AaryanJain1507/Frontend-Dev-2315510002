Security Note on Autocomplete

Turning off **autocomplete** on a form or an input field (especially for sensitive data like passwords, PINS, or security questions) can improve security in the following ways:

  • Prevents Data Exposure: It stops the browser from saving or suggesting sensitive information. If a user is on a shared or public computer, this prevents the next user from easily accessing saved credentials by simply clicking or typing the first character.
  • Mitigates XSS/CSRF Risk: While not a primary defense, it reduces the risk of malicious scripts (Cross-Site Scripting) or attacks (Cross-Site Request Forgery) from automatically harvesting or submitting saved user data from the browser's autofill cache.

12. Reserved Characters and Symbols using HTML Entities

Reserved Characters

To display the following special characters in HTML, we use their respective entities:

  • Less Than Sign (<): &lt;
  • Greater Than Sign (>): &gt;
  • Ampersand (&): &amp;
  • Double Quote ("): &quot;
  • Single Quote ('): &apos;

Common Symbols

Common symbols also use entities to ensure consistent rendering across browsers:

  • Copyright Symbol (©): &copy; (or &#169;)
  • Trademark Symbol (™): &trade; (or &#8482;)
  • Registered Trademark Symbol (®): &reg; (or &#174;)

Example sentence: The code `if (x < 10 && y > 5)` is protected by Copyright © 2025. This is a Trademark ™ product (Registered ®).

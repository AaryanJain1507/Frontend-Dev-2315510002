16. URI Encoding Example

URI (Uniform Resource Identifier) encoding is necessary to ensure that all characters used in a URL are within the allowed set of ASCII characters. Special characters, such as spaces, must be converted to a percent-encoded format.

Original Link (Not Encoded)

https://example.com/search?query=HTML & CSS

Correct Encoded Link

In URI encoding, the **space character** is commonly encoded as %20 (or sometimes as a plus sign '+', though %20 is the official standard for spaces in the query part). The ampersand (&) is also a reserved character in a query string and should be encoded as %26 if it's meant to be part of the search term.

https://example.com/search?query=HTML%20%26%20CSS
